### 函数卡模板（复制区）

```markdown
#### <函数名>
- 签名：<函数名>(<参数1:类型, 参数2:类型, ...>) -> <返回类型>
- 用途：一句话说清解决什么问题
- 参数说明：逐个写含义；哪个可空、哪个有默认值单独标出
- 返回与空值：入参为 NULL 返回什么；异常输入返回什么
- 示例：SELECT <函数名>(...)  -- 结果：
- 什么时候不该用：与哪个内置/清单内函数容易混、什么场景不要用它
- 备注：版本限制、性能注意、已知坑（没有写「无」）
- 来源：wiki 页面名/链接（便于日后人工复核）
```

### 合成示例（照这个粒度填，示例函数为虚构）

#### my_date_format
- 签名：my_date_format(dt STRING, fmt STRING) -> STRING
- 用途：按公司统一格式把日期字符串转成目标格式
- 参数说明：dt 为 `yyyyMMdd` 字符串；fmt 只支持 `yyyy-MM-dd` / `yyyy/MM/dd`
- 返回与空值：dt 为 NULL 返回 NULL；dt 格式不对返回 NULL（不报错）
- 示例：SELECT my_date_format('20261106', 'yyyy-MM-dd')  -- 结果：2026-11-06
- 什么时候不该用：dt 已经是 DATE 类型时不要用，先转字符串会丢精度校验
- 备注：无
- 来源：wiki「平台 UDF 手册」合成示例页
