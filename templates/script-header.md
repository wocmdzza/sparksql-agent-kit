# 正式脚本注释头模板（占位，待 使用者 提供真实模板后替换）

> 仅正式脚本（长期调度、落表产出）需要注释头；测试脚本
> （单次数据分析等一次性脚本）不需要，Agent 不要强加。
> 真实模板由 使用者 提供，在替换进来之前 Agent 不许自创模板里没有的行，
> 只执行下面这一条已确认的规则。

## 已确认规则

- 注释头中有一行 `@Modify`，用于描述变更：日期 + 改动简述。
- 新建正式脚本时 `@Modify` 写创建信息；每次修改正式脚本，
  必须新增/更新 `@Modify` 记录（格式以真实模板为准，
  占位格式如下）。

```sql
-- @Modify: YYYY-MM-DD <改动简述>
```

## 待 使用者 补充

- [ ] 注释头全文（各行字段名、顺序、是否还有 @Author/@Desc/输入输出表等行）
- [ ] `@Modify` 是只保留最新一条，还是逐条累积历史
- [ ] 日期格式（`YYYY-MM-DD` 还是其他）
